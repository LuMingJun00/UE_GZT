贴图工具 EkkoPBR

启动/停止本机贴图生成服务（127.0.0.1:5173）。可生成 BaseColor / Normal / Roughness / Metalness / Height / AO 六通道无缝贴图。拖入贴图：把 JPG / PNG / WebP 直接拖到 EkkoPBR 页面的材质预览窗口（预览球区域），即自动导入「输入源」。

🎮

打开 UE 工程

用 UE 5.7 打开内置工程 SceneWorkbench。贴图放入 Content 后会自动导入；模型用 Content Browser 拖入。

📁

素材库 / 输出目录

模型、贴图、HDRI、音效统一收纳区。EkkoPBR 导出贴图经「收纳入库」自动归位到这里。

🗂️

收纳入库 / 快照备份

把下载目录中 EkkoPBR 导出的贴图按命名规范归位；或将工程 Content+Config 打包为带日期 ZIP 快照。
